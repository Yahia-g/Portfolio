1. HTML Basics

HTML (HyperText Markup Language) is the structure of a page. It is made of elements written with tags.

<p class="intro">Hello world</p>
 │   └─ attribute ─┘  └content┘  └ closing tag
 └ opening tag
▶ Output

Hello world

Minimum page skeleton

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Page</title>      <!-- shows in browser tab -->
</head>
<body>
  <h1>Hello!</h1>             <!-- everything visible goes here -->
</body>
</html>
▶ Output
My Page

Hello!

Remember: <head> = info about the page (title, CSS links). <body> = what the user sees.

3. CSS Basics

CSS (Cascading Style Sheets) controls how HTML looks. A CSS rule has a selector and a declaration block:

selector {
  property: value;
}

h1 {
  color: navy;          /* text color */
  font-size: 32px;      /* text size */
  background-color: #eee;
  text-align: center;
  margin: 20px;         /* space OUTSIDE the element */
  padding: 10px;        /* space INSIDE the element */
  border: 2px solid black;
}
▶ Output — for <h1>Hello</h1>

Hello

Box model: every element is a box → content → padding → border → margin (inside to outside).

Margin: the space outside the border

Margin pushes other elements away. It is always transparent and never takes the element's background color. Padding is the space inside the border, and it does take the background color.

.box {
  margin: 20px;              /* outside: pushes neighbors away */
  border: 6px solid #333;
  padding: 20px;             /* inside: between border and content */
}
▶ Output — box model (colors added to show each layer)
margin (transparent in real life)
padding (black line = border)
content

Margin shorthand: 1 to 4 values, clockwise from the top

margin: 20px;               /* all 4 sides                      */
margin: 10px 40px;          /* top+bottom | left+right          */
margin: 5px 40px 20px;      /* top | left+right | bottom        */
margin: 0 0 0 60px;         /* top | right | bottom | left      */
margin-top: 10px;           /* or set one side: -top -right -bottom -left */
▶ Output — orange = margin area, blue = element
margin: 20px
margin: 10px 40px
margin: 5px 40px 20px
margin: 0 0 0 60px
Memory trick: 4 values go T R B L ("TRouBLe"), which is clockwise starting at the top.

Centering a block with margin: auto

.box {
  width: 200px;       /* needs a width! */
  margin: 0 auto;     /* 0 top/bottom, auto left/right = centered */
}
▶ Output
centered box

Margin collapse: vertical margins don't add up

When two block elements are stacked, their top and bottom margins overlap, and only the bigger one is used. Left/right margins never collapse.

.first  { margin-bottom: 20px; }
.second { margin-top: 30px; }
/* gap between them = 30px, NOT 50px */
▶ Output
.first (margin-bottom: 20px)
.second (margin-top: 30px)

The orange gap is 30px: the larger margin wins.

Quick facts: margins can be negative (margin-top: -10px pulls an element up). Inline elements like <span> and <a> ignore top/bottom margin. Use * { margin: 0; } to remove the browser's default margins.

4. Three Ways to Add CSS

① Inline — inside the tag (avoid, hard to maintain)

<p style="color: red; font-size: 20px;">Red text</p>
▶ Output

Red text

② Internal — a <style> tag in the <head> (one page only)

<head>
  <style>
    p { color: red; }
  </style>
</head>
▶ Output — every <p> on the page

First paragraph

Second paragraph

③ External — a separate .css file (best practice ✅)

/* style.css */
p { color: red; }
▶ Output

Nothing yet. A CSS file shows nothing on its own until an HTML page links to it ↓

<!-- index.html -->
<head>
  <link rel="stylesheet" href="style.css">
</head>
▶ Output — every <p> on every page that links style.css

Specificity — who wins a conflict?

Inline style > #id > .class / :hover / [attr] > element. If equal, the rule written last wins.

p      { color: black; }  /* weakest   */
.note  { color: blue;  }  /* stronger  */
#title { color: red;   }  /* strongest */
▶ Output

<p> → black

<p class="note"> → blue (class beats element)

<p class="note" id="title"> → red (id beats class)

Rule of thumb: use class for styling, id for unique things (links like #section, JavaScript).

Folder structure

├── about.html

Step 1 — Write the CSS file (css/style.css)

body {
  font-family: Arial, sans-serif;
  background: #f4f4f4;
  margin: 0;
}
.card {
  background: white;
  padding: 20px;
  border-radius: 8px;
}
▶ Output

Nothing yet. This file needs to be linked first (Step 2).

Step 2 — Link it inside <head>

<head>
  <meta charset="UTF-8">
  <title>Home</title>
  <link rel="stylesheet" href="css/style.css">
</head>
▶ Output
Home
Empty light-gray page in Arial (the body styles are applied, but there's no content yet)

Step 3 — Use the classes in HTML

<body>
  <div class="card">
    <h1>Welcome</h1>
  </div>
</body>
▶ Output

Welcome

File paths cheat sheet

PathMeans
href="style.css"Same folder as the HTML file
href="css/style.css"Inside the css subfolder
href="../style.css"One folder up
href="https://…/x.css"Online file (e.g. Google Fonts, Bootstrap)

Linking HTML pages to each other

<a href="about.html">About me</a>        <!-- another page -->
<a href="#contact">Jump to contact</a>   <!-- section with id="contact" -->
<a href="about.html#skills">Skills</a>   <!-- section on another page -->
▶ Output
About me Jump to contact Skills

Links are inline, so they sit side by side. Clicking one opens that page or scrolls to that section.

CSS not working? Check: ① the path/filename spelling (case-sensitive online), ② rel="stylesheet" is there, ③ the <link> is in the <head>, ④ hard-refresh with Ctrl + F5.

8. Complex Div Example: a Portfolio Layout

Real pages are just divs inside divs. Each div is a box, and CSS (mostly flexbox) decides how the boxes sit next to each other. Here is the plan:

.page                        ← outer wrapper (centers everything)
├── .topbar                  ← flex row: logo LEFT, links RIGHT
│   ├── .logo
│   └── .links  (3 × <a>)
├── .layout                  ← flex row: sidebar + content side by side
│   ├── .sidebar             ← fixed width column
│   │   ├── .avatar          ← circle, text centered with flex
│   │   ├── <h4> name
│   │   └── <p> role
│   └── .content             ← takes remaining space, wraps cards
│       ├── .card
│       ├── .card
│       └── .card
└── .footer

The HTML

<div class="page">

  <div class="topbar">
    <div class="logo">MyPortfolio</div>
    <div class="links">
      <a href="#">Home</a>
      <a href="#">Projects</a>
      <a href="#">Contact</a>
    </div>
  </div>

Divs stack vertically by default (they are block elements). CSS turns this list into a layout ↓

The CSS

.page {
  max-width: 700px;
  margin: 0 auto;                 /* center the whole page */
  border: 1px solid #ccc;
  border-radius: 10px;
  overflow: hidden;               /* clip children to the rounded corners */
  font-family: Arial, sans-serif;
}

/* ---- Top bar ---- */
.topbar {
  display: flex;
  justify-content: space-between; /* logo left, links right */
  align-items: center;            /* vertically centered */
  background: #1e2230;
  color: white;
  padding: 12px 20px;
}
.logo { font-weight: bold; font-size: 18px; }
.links a { color: white; text-decoration: none; margin-left: 16px; }
.links a:hover { text-decoration: underline; }

/* ---- Main area: sidebar + content ---- */
.layout {
  display: flex;
  flex-wrap: wrap;                /* stack on small screens */
  gap: 20px;
  padding: 20px;
}
.sidebar {
  flex: 0 0 160px;                /* don't grow, don't shrink, 160px wide */
  background: #f4f4f4;
  border-radius: 8px;
  padding: 20px;
  text-align: center;
}
.avatar {
  width: 70px;
  height: 70px;
  border-radius: 50%;             /* square → circle */
  background: #2f6fde;
  color: white;
  font-size: 24px;
  font-weight: bold;
  display: flex;                  /* center text inside the circle */
  justify-content: center;
  align-items: center;
  margin: 0 auto 10px;            /* center the circle itself */
}
.sidebar h4 { margin: 0; }
.sidebar p  { margin: 4px 0 0; color: #666; }

.content {
  flex: 1 1 250px;                /* grow to fill the remaining space */
  display: flex;
  flex-wrap: wrap;                /* cards wrap to new lines */
  gap: 12px;
  align-content: flex-start;
}
.card {
  flex: 1 1 140px;                /* each card at least ~140px, share space */
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 12px;
}
.card:hover { border-color: #2f6fde; }
.card h4 { margin: 0 0 6px; }
.card p  { margin: 0; color: #666; font-size: 14px; }

/* ---- Footer ---- */
.footer {
  background: #f4f4f4;
  text-align: center;
  padding: 10px;
  font-size: 14px;
  color: #666;
}

How it works, div by div

DivJobKey CSS
.pageOuter wrapper that holds everything and centers itmax-width + margin: 0 auto; overflow: hidden so children don't poke out of the rounded corners
.topbarNavigation bardisplay: flex + justify-content: space-between pushes its 2 children to opposite ends
.layoutPuts sidebar and content side by sidedisplay: flex makes children sit in a row; gap adds space between them; flex-wrap stacks them on narrow screens
.sidebarFixed-width profile columnflex: 0 0 160px = never grow, never shrink, always 160px
.avatarRound profile circleborder-radius: 50% makes the circle; flex inside centers "YA"; margin: 0 auto centers the circle
.contentHolds the project cardsflex: 1 = take all leftover space. It is both a flex child (of .layout) and a flex container (for the cards)
.cardOne project boxflex: 1 1 140px = start at 140px, grow/shrink to share the row evenly, wrap when there's no room
.footerBottom stripA normal block div, so it automatically takes the full width
flex: grow shrink basis is the key to layouts. flex: 1 = "fill the space". flex: 0 0 200px = "stay exactly 200px". flex: 1 1 150px = "about 150px, but flexible".
How to build any layout: ① sketch the boxes, ② write the nested divs (like the tree above), ③ put display: flex on every div whose children should sit in a row, ④ add spacing with gap, padding and margin.
